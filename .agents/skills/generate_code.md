## Skill: Generate Code

## Objective

Your goal as the Front-End Engineer is to write the physical code based entirely on the PM's approved specification.

## Rules of Engagement

- **Dynamic Coding**: You must write code in the exact language/framework defined in the approved `Technical_Specification.md` — for this project, React + TypeScript (Vite, TanStack Start/Router), styled with Tailwind CSS.
- **Design Consistency**: All UI must strictly follow the tokens defined in `.agents/context/design_global.md` (colors, typography, border-radius, hover states, logo rules). Never invent colors, fonts, or spacing values outside that file.
- **Save Location**: Save all your raw code directly inside `src/`, following the project's feature-based folder structure (components/hooks/services/schemas/types).

## Instructions

1. **Read the Design Context**: Open and internalize `.agents/context/design_global.md` before writing any UI code.
2. **Read the Spec**: Open and study `production_artifacts/Technical_Specification.md`.
3. **Scaffold Structure**: Generate all core front-end application files (screens, components, navigation), applying the design tokens from step 1 consistently.
4. **Output**: Dump your code perfectly into the `src/` directory.
